ИНТЕГРАЦИИ

Подключается к тому,
где уже идёт работа.

Каналы общения подключаются официально, без «серых» решений. Для связи с вашими системами есть открытый интерфейс программирования и вебхуки.

WhatsApp Business API.

Официальное подключение через Meta. Номер остаётся вашим, диалоги ведутся в Chatyr, шаблоны для исходящих сообщений.

Telegram.

Бот компании подключается по токену за две минуты. Несколько ботов в одном окне.

Instagram.

Direct, комментарии и упоминания бизнес-аккаунта через официальный интерфейс Meta.

Чат на сайте.

Виджет для любого сайта: Tilda, WordPress, Bitrix, самописные. Одна строка кода.

Электронная почта.

Общий ящик поддержки как канал: письма клиентов попадают в тот же список, ответ уходит с вашего адреса.

CRM и учётные системы.

Открытый API и вебхуки: новые диалоги, сообщения и контакты можно передавать в Bitrix24, amoCRM, 1С и любую систему с API. Выгрузка контактов файлом.

Входящие через API.

Свой канал: сообщения из любого источника, например из мобильного приложения, попадают в общее окно.

Оплата.

Счёт для организаций и ИП, перевод из любого банка.
