Как подключить WhatsApp к Chatyr

TelegramWhatsAppInstagramВсе каналы

Статус на 5 ноября 2026. Приложение Chatyr отправлено на проверку в Meta и ожидает решения. Подключение WhatsApp и Instagram мы выполняем вручную: если у компании есть WhatsApp Business Account и доступ к API или профессиональный аккаунт Instagram с бизнес-портфолио, канал подключается сейчас. Что нужно подготовить, описано ниже.

Для переписки внутри Chatyr нужен официальный WhatsApp Business Platform API. Если сейчас у вас только WhatsApp на телефоне, начните с Telegram или чата на сайте, а API подготовьте отдельно.

WABA это аккаунт, а не отдельный тариф

WABA означает WhatsApp Business Account в платформе Meta. Установленное приложение WhatsApp Business само по себе не даёт API-доступ. В Chatyr сейчас работает ручное подключение; встроенная регистрация номера через Meta ещё не настроена.

Если API ещё нет

  1. Продолжайте тест Chatyr без WhatsApp. Тестовая среда, чат на сайте и Telegram-бот позволяют проверить базу знаний, ИИ и работу сотрудника.
  2. Выберите официальный путь подключения. Можно оформить Cloud API в собственном приложении Meta, если у компании есть такой доступ, или пройти регистрацию у официального провайдера WhatsApp Business Platform.
  3. Владелец компании проходит подтверждения. Подготовьте данные юридического лица, сайт, доступ к номеру для кода подтверждения и право управлять бизнес-аккаунтом. Создание аккаунта разработчика каждому сотруднику клиента не требуется при регистрации через провайдера.
  4. До оплаты провайдера уточните совместимость. Нужен прямой Cloud API с доступными реквизитами или поддерживаемый коннектор. Ключ произвольного сервиса нельзя вставить в поле Meta Access Token. Сравните абонплату, стоимость сообщений, условия номера и отключения.

Можно сохранить приложение на телефоне?

У некоторых официальных провайдеров есть Coexistence: API и приложение WhatsApp Business работают на одном номере. Возможность зависит от аккаунта, региона и провайдера. Встроенного подключения Coexistence в Chatyr сейчас нет. Не удаляйте приложение и не отключайте действующий номер ради теста без подтверждённого плана перехода; перенос истории не обещается.

Пример официального пути: инструкция провайдера 360dialog по Coexistence. Это внешний сервис с собственными условиями; регистрация или оплата по ссылке не являются частью бесплатного доступа Chatyr.

Если Cloud API уже готов

  1. Откройте кабинет → «Подключить WhatsApp». В рабочем кабинете тот же путь: Настройки → Источники / Каналы → Добавить → WhatsApp → ручная настройка Cloud API.
  2. Подготовьте три значения из аккаунта Meta, которому принадлежит номер: WABA ID: идентификатор WhatsApp Business Account; Phone Number ID: идентификатор номера в API, не сам номер телефона; Access Token: действующий токен с правами на этот WABA и номер.
  3. Если мастер предлагает шаги создания приложения и регистрации номера, используйте уже подготовленное приложение и номер. Вставьте WABA ID, Phone Number ID и Access Token в соответствующие поля и запустите проверку реквизитов.
  4. Проверьте найденный номер и название канала, затем подтвердите подключение. Если мастер показывает шаг webhook, следуйте его текущим указаниям и дождитесь подтверждения подписки на события. Адреса из чужих аккаунтов не копируйте.
  5. Добавьте сотрудников канала и пройдите проверку сообщения ниже. При ошибке прав или webhook не оплачивайте повторно и не создавайте дубликаты номера.

Токен вводится только в защищённую форму app.chatyr.kz. Временный тестовый токен Meta может истечь: для регулярной работы нужен токен и доступы, соответствующие производственной настройке компании. Не отправляйте ключи в поддержку письмом.

Если номер подключён через провайдера

Попросите провайдера уточнить способ интеграции. Для прямого Cloud API используйте путь выше. Для уже настроенного 360dialog откройте форму WhatsApp и раскройте подсказку «WhatsApp: что нужно для подключения» внизу справа. В ней выберите 360dialog; в открывшейся форме доступны название канала, номер в международном формате и API Key провайдера.

Ключ 360dialog отличается от токена Meta. Не переводите действующий номер на другой способ и не заменяйте его webhook, пока не проверено, как это повлияет на нынешний сервис. Поставка доступа к Chatyr не означает заключённый договор с провайдером.

За что может взиматься плата

  • Chatyr: выбранный тариф или предоставленный владельцем бесплатный полный доступ.
  • Meta: сообщения по действующим правилам и категориям. По текущим правилам Meta сервисные ответы внутри 24 часов после сообщения клиента бесплатны со стороны Meta; шаблонные сообщения могут тарифицироваться.
  • Провайдер: возможны абонплата и дополнительные комиссии, даже когда Meta не берёт плату за конкретный ответ.

Бесплатные 7 дней Chatyr не покрывают расходы Meta или внешнего провайдера. Точные ставки зависят от страны получателя и категории: официальные цены WhatsApp.

Проверьте входящее и ответ

  1. С другого номера отправьте новое сообщение на подключённый бизнес-номер.
  2. Откройте соответствующий канал в Chatyr. Убедитесь, что сообщение появилось именно в аккаунте вашей компании.
  3. Ответьте из Chatyr и проверьте доставку на телефоне отправителя. ИИ проверяйте отдельно, с опубликованными знаниями и доступной квотой.
  4. Если ответ вне разрешённого окна отклонён, проверьте правила шаблонов Meta. Наличие номера в списке каналов ещё не подтверждает доставку.
У нас нет кабинета разработчика Meta. Это конец?

Нет. Для знакомства с Chatyr WABA не нужен. Для WhatsApp можно пройти официальный путь у провайдера; бизнес-аккаунт и номер остаются у вашей компании. Провайдер не гарантирует отмену ограничений Meta, но позволяет не создавать клиентское приложение самостоятельно.

Можно подключить обычный WhatsApp по QR-коду?

В Chatyr нет подключения обычного личного WhatsApp через эмуляцию WhatsApp Web. QR-код официального Coexistence у провайдера это другой механизм, с отдельными условиями. Его наличие в инструкции провайдера не означает, что такая кнопка уже есть в Chatyr.

Форма выдаёт ошибку доступа

Проверьте, что WABA ID, Phone Number ID и токен относятся к одному бизнес-номеру, а токен не истёк. Сохраните текст ошибки без ключей. Повторная оплата тарифа Chatyr не снимает ограничения Meta.
